ORN · Row 8.4 · Design reference

Calm, precise, quick

The app should feel like a well-made study instrument: quiet surfaces so the chemistry stands out, one clear way to do each thing, and motion that explains what happened. Every screen is built from the parts on this page. If a screen needs something not shown here, it goes under REVIEW REQUIRED, not into code.

Five rules. 1. Content first: chrome is quiet (hairlines, no heavy bars, at most one primary button per view). 2. One way per thing: one button set, one chip, one card, one list row, one icon style. 3. Depth means something: canvas < surface < raised (popovers, toasts, floating map controls). Never more than two floating layers. 4. Motion explains: 120–260 ms, opacity and transform only, none with reduced motion. 5. Both themes are first class: every part is checked in light AND dark.

Token names are the contract. Map them onto the app's token file (8.4a); keep 8.4a names where they already mean the same thing and alias the rest. No raw colour values outside the token file (the 8.4a guard extends to colours).

Structure drawings stay on paper. RDKit structures keep their textbook colours (black bonds, red O, blue N). In the dark theme they sit on a --paper card (near-white, rounded, hairline) instead of being inverted. Inverting chemistry colours would be wrong; a paper card reads like a page of a book and is honest.

4. Icons

Lucide (ISC licence; record it in DEPENDENCIES.md and the About credits), outline, stroke 1.75, 16 px in controls, 20 px in the phone tab bar. Only the icons below are vendored, as single-colour SVG files drawn through CSS mask-image with background: currentColor. That keeps them out of the JavaScript bundle and inside the "SVG only through the sanitiser or img" rule (a CSS image, no markup injected). Every icon-only button has an accessible name and a tooltip.

12. Accessibility and quality bars (both themes)

ContrastText ≥ 4.5:1, large text and icons ≥ 3:1, in light AND dark (axe in both themes).
FocusEvery control and every map box reachable by keyboard, visible ring, logical order. A "Skip to content" link first.
MotionAll animation off with reduced motion (device or Settings).
ZoomUsable at 200% browser zoom and at "Text size 125%": no clipped controls, no horizontal page scroll (the map may pan).
StabilityNo layout shift after load (CLS ≤ 0.02); skeletons hold the space.
Speed feelPress feedback ≤ 100 ms; panels open in one frame and finish animating in 260 ms; lazy chunks prefetched when the browser is idle after first load.
TitlesEach view sets the tab title ("Alcohols · Map · ORN").
