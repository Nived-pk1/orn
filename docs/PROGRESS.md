**Delivered**

**Verification performed**

- Runtime smoke (tsx): the minimal fixture parses and round-trips unchanged; unknown keys, wrong prefixes, prefix/kind mismatch, product→reagent refs, bidi characters, blank names, `javascript:`/credential URLs, oversized SMILES, NaN/Infinity and missing arrays are rejected; Unicode names and large molfiles accepted.
- `check:size` and `check:hardcode` pass.
